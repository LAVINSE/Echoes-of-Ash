# Echoes of Ash — 데이터 문서

> 콘텐츠 데이터(적·조우·카드·유물·이벤트) 구성안의 단일 정리처. **에셋 제작 = 아트 작업 시점 (사용자 결정)** — 이 문서는 그 시점의 제작 명세다.
> 기준 문서: 기획서 v3.2 + Phase 2 개발스케줄 · 작성일: 2026-07-30 (개정 1 — P2-M7 7-6 보스 구성안 편입)
> **모든 수치는 잠정 (밸런스 영역 — 파티 3인 기준).** 표시명·세계관 명칭은 리소스 단계에서 자유 변경 (코드명 유지).

---

## 1. 공통 기준

| 항목 | 잠정 기준 |
|------|-----------|
| 파티 | 3인 기준 (인당 HP 26~32 · 공유 AP 3 · 카드 피해 ~6) |
| 파티 SAN | 최대 100 / 광기 임계 40 |
| 적 SAN | 전 개체 필수 스탯 (기획서 3-2) — 광기 패턴(`isSanityAction`)은 필요한 적만 정의 (콘텐츠 비용 제어) |
| 층 표기 | **0-based** (입구층 = 0, 12층 맵 = 0~11 — 잿불 침식 표기와 일치) |
| 등장 구간 | `EnemyData.SpawnRange` — `(0, 0)` = 미설정 = 무제한 (잠정 규칙) |
| 조우 등장 층 | 구성 적 전원의 SpawnRange **자동 결합** (조우 에셋에 층 필드 없음 — `IsSpawnableAtFloor`) |
| 행동 구성 | **기존 효과 블록만 사용** — 피해(DamageEffect) / 방어막(BlockGainEffect) / 상태이상 부여(StatusEffect) / 정신력 변화(SanityChangeEffect) — 코드 0줄 원칙 |
| 사용 상태이상 | 화상 · 출혈 · 중독 · 취약 (기절·도발은 적 행동에 미사용) |
| 패턴 우선순위 | **광기 패턴 > HP 페이즈 > 기본** (`EnemyAI.SelectPatterns` — M4 계약. 전환 판정 = 턴 경계) |

### 2-3. 보스 (`EEnemyType.Boss` — ⚠ enum 값 존재 확인, 4장 체크리스트 7번)

| # | 코드명 | 표시명 (잠정) | 등장 층 | 대상 규칙 | HP | SAN 최대/시작/임계 | 설계 축 |
|---|--------|----------------|---------|-----------|-----|--------------------|---------|
| 13 | `Enemy_AshMonarch` | 잿더미의 군주 | 미설정 (0,0) | **어그로** | 150 | 120/120/40 | **HP 페이즈 2단 + 광기 패턴 조합** — 다단 페이즈 최저 임계값 규칙·광기의 페이즈 우선 계약 실가동 |

- **등장 구간 = 미설정 (0,0):** 보스는 전용 풀(`bossEncounters`)에서만 추첨되고 보스 노드는 최종 층 고정 — 층 필터가 개입할 여지가 없어 SpawnRange 불요 (잠정 규칙 ① "미설정 = 무제한" 그대로)
- **대상 규칙 = 어그로:** 엘리트 3종이 지정/무작위/어그로를 각 1종씩 배치했고, 보스전은 도발·어그로 조작 카드의 가치가 가장 큰 무대 — 탱커 운용 보상 지점

**행동 패턴 (기존 효과 블록만 — 피해/방어막/상태이상/정신력):**

| 상태 | 순환 패턴 |
|------|-----------|
| 기본 "옥좌의 군주" (HP > 60%) | ① 군주의 위엄 = 방어막 +10 + 취약 1 → ② 철퇴 강타 = 피해 14 → ③ 잿불 포고 = 정신력 -8 |
| HP 페이즈 1 "타오르는 옥좌" (HP ≤ 60%) | ① 옥좌의 불길 = 피해 9 + 화상 2 → ② 재의 파도 = 피해 6 x2 + 정신력 -4 → ③ 왕의 수호 = 방어막 +8 |
| HP 페이즈 2 "붕괴하는 군주" (HP ≤ 25%) | ① 최후의 격노 = 피해 8 x2 + 화상 1 → ② 무너지는 왕좌 = 피해 12 + 정신력 -6 — **방어 행동 없음 (전면 공세)** |
| 광기 패턴 "왕좌 잃은 광인" (SAN < 40) | ① 광란 난타 = 피해 5 x3 → ② 공허한 절규 = 정신력 -10 — **방어 없음·상태이상 없음·2행동 순환 (예측 용이)** |

**설계 의도 — 광기 = "탈진 락" (⚠ 사용자 결정 후보 — 6장 미결정 3번):**

- **광기 패턴은 HP 페이즈에 우선한다** (`EnemyAI.SelectPatterns` — M4 우선순위 계약, 코드 0줄). 정신 공격에 투자하면 보스를 페이즈 2("붕괴하는 군주") 진입 전에 광기에 **가둘 수 있다** — HP 러시(페이즈 격화를 정면 돌파) vs SAN 투자(가장 위험한 페이즈를 봉인)의 전략 분기가 기존 우선순위 계약만으로 성립
- 락이 공짜가 되지 않도록: 광기 패턴은 방어·취약이 빠져 약체화되지만 **SAN 압박은 유지·집중** (절규 -10) + **SAN 120 = 상당한 투자 요구** (전령 시작 70과 대비되는 보스급 정신 내성)
- 챕터 1 내 역할 분담: **전령 = 광기 진입이 리스크** (건드리면 강화) / **보스 = 광기 진입이 보상** (페이즈 봉인) — 정신 공격 빌드가 "언제 쓰고 언제 아끼는가"를 챕터 1 안에서 학습 (기획서 3-2 "적마다 다르게 설계 가능" 이행)
- 광기 이탈(적 SAN 자연 회복 도입 시) = 턴 경계 재평가로 HP 페이즈 자동 복귀 — 기존 계약이 자연 처리

## 4. 에셋 제작 체크리스트 (아트 작업 시점)

1. HP/SAN 스탯 에셋 준비 (SWStatOverride — 기존 스탯 에셋 재사용, 수치 = 2장 표)
2. 상태이상 정의 에셋 확인: 화상·출혈·중독·취약 `StatusEffectData` 4종을 챕터 SO `statusDatas`에 등록
3. 적 13종 `Enemy_` 에셋 생성 — 데이터 윈도우 적 탭 (SpawnRange = 0-based, 보스는 미설정)
4. 조우 15종 `EnemyEncounter_` 에셋 생성 + 배치 좌표 + 엘리트/보스 드랍 테이블 연결
5. 챕터 SO `battleEncounters` 10종 / `eliteEncounters` 4종 / `bossEncounters` 1종 등록 (보스 빈 풀 폴백 경고 해소)
6. 몬스터 드랍형 카드 슬롯 3건은 비워둠 — 7-1 카드 제작 시 연결 ("골렘의 핵"·"전령의 속삭임"·"군주의 잿불")
7. **`EEnemyType.Boss` enum 값 확인** — 없으면 기존 값 뒤 추가 (직렬화 안전 — Taunt 신설 전례). `RewardConfigData` 골드 3구간(일반/엘리트/보스)의 보스 판정 키와 정합 확인
8. 보스 `Enemy_AshMonarch` 에셋 생성 — HP 페이즈 2단(`PhasePatterns` 임계 0.6·0.25) + 광기 패턴(`SanityActions`) 동시 등록

## 5. 실검증 시나리오 (아트 작업 시점 이월분과 일괄)

초반 층 = 들쥐/신도 계열만 등장 → 후반 층 = 파수꾼/운반자 계열 → 필터 공집합 층 = 폴백 경고 + 전투 성립 → 어그로(사냥개)·지정 고정(포식자·파수꾼) 대상 규칙 체감 → 골렘 HP 50% 이하 = 패턴 전환 + 의도 갱신 → 전령 SAN 50 미만 = 광기 패턴 전환 → SAN 압박 누적 = 파티 광기 진입 → 상태이상 4종 틱 동작

**보스 추가분 (7-6):** 보스 노드 진입 = 전용 풀 추첨 → HP 60% 이하 = 페이즈 1 전환 → HP 25% 이하 = 페이즈 2 전환 (**최저 임계값 우선 — 다단 HP 페이즈 첫 실가동**, 두 임계 동시 충족 시 0.25 선택) → 정신 공격 누적 SAN < 40 = **광기 패턴이 HP 페이즈를 덮음** (페이즈 2 상태에서도 광기 패턴 순환) → 전환은 전부 턴 경계(라운드 종료) 반영·의도 갱신 → 보스 처치 = `EndDungeon(true)` → 회수 전량 + 마을 복귀

## 6. 미결정 사항

1. **광기 보상 공통 이득** (기획서 3-2 임시 제안 — 예: 광기 상태 적 받는 피해 +25%) — 미구현. 광기 패턴 없는 적 11종에 대한 정신공격 가치 보장책. 구현 시 `StatusDamageCalculator` 래핑 영역(상시 배율 전례) + 수치 = Balance 외부화. 채택 여부 = 프로토타입 검증 후 확정 원칙.
2. `HeraldEscort` 조우의 신도 등장 구간 상향 여부 (3-2절 ⚠).
3. **보스 광기 방향** — 채택안 = "탈진 락" (광기 = 페이즈 봉인 보상, 2-3절 설계 의도). 대안 = 전령식 강화 통일 (광기 = 보스도 강화 — 정신 빌드의 보스 보상 지점이 사라지는 대신 "정신 오염형 보스" 세계관 강화). **채택 여부 = 사용자 확정 + 프로토타입 검증.**
4. 보스 유물 지급 시점·방식 (보상 화면 뷰 = 아트 시점 이월분과 연동) — 슬롯만 예약.
