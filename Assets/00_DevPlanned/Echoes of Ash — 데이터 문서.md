# Echoes of Ash — 데이터 문서

> 콘텐츠 데이터(적·조우·카드·유물·이벤트) 구성안의 단일 정리처. **에셋 제작 = 아트 작업 시점 (사용자 결정)** — 이 문서는 그 시점의 제작 명세다.
> 기준 문서: 기획서 v3.2 + Phase 2 개발스케줄 · 작성일: 2026-07-30 (초판 — P2-M7 7-3 적 12종 + 조우 14종 구성안)
> **모든 수치는 잠정 (밸런스 영역 — 파티 3인 기준).** 표시명·세계관 명칭은 리소스 단계에서 자유 변경 (코드명 유지).

---

## 1. 공통 기준

| 항목 | 잠정 기준 |
|------|-----------|
| 파티 | 3인 기준 (인당 HP 26~32 · 공유 AP 3 · 카드 피해 ~6) |
| 파티 SAN | 최대 100 / 광기 임계 40 |
| 적 SAN | 전 개체 필수 스탯 (기획서 3-2) — 광기 패턴(`isSanityAction`)은 필요한 적만 정의 (콘텐츠 비용 제어) |
| 층 표기 | **0-based** (입구층 = 0, 12층 맵 = 0~11 — 잿불 침식 표기와 일치) |
| 등장 구간 | `EnemyData.SpawnRange` — `(0, 0)` = 미설정 = 무제한 (잠정 규칙) |
| 조우 등장 층 | 구성 적 전원의 SpawnRange **자동 결합** (조우 에셋에 층 필드 없음 — `IsSpawnableAtFloor`) |
| 행동 구성 | **기존 효과 블록만 사용** — 피해(DamageEffect) / 방어막(BlockGainEffect) / 상태이상 부여(StatusEffect) / 정신력 변화(SanityChangeEffect) — 코드 0줄 원칙 |
| 사용 상태이상 | 화상 · 출혈 · 중독 · 취약 (기절·도발은 적 행동에 미사용) |

## 4. 에셋 제작 체크리스트 (아트 작업 시점)

1. HP/SAN 스탯 에셋 준비 (SWStatOverride — 기존 스탯 에셋 재사용, 수치 = 2장 표)
2. 상태이상 정의 에셋 확인: 화상·출혈·중독·취약 `StatusEffectData` 4종을 챕터 SO `statusDatas`에 등록
3. 적 12종 `Enemy_` 에셋 생성 — 데이터 윈도우 적 탭 (SpawnRange = 0-based)
4. 조우 14종 `EnemyEncounter_` 에셋 생성 + 배치 좌표 + 엘리트 드랍 테이블 연결
5. 챕터 SO `battleEncounters` 10종 / `eliteEncounters` 4종 등록
6. 몬스터 드랍형 카드 슬롯 2건은 비워둠 — 7-1 카드 제작 시 연결

## 5. 실검증 시나리오 (아트 작업 시점 이월분과 일괄)

초반 층 = 들쥐/신도 계열만 등장 → 후반 층 = 파수꾼/운반자 계열 → 필터 공집합 층 = 폴백 경고 + 전투 성립 → 어그로(사냥개)·지정 고정(포식자·파수꾼) 대상 규칙 체감 → 골렘 HP 50% 이하 = 패턴 전환 + 의도 갱신 → 전령 SAN 50 미만 = 광기 패턴 전환 → SAN 압박 누적 = 파티 광기 진입 → 상태이상 4종 틱 동작

## 6. 미결정 사항

1. **광기 보상 공통 이득** (기획서 3-2 임시 제안 — 예: 광기 상태 적 받는 피해 +25%) — 미구현. 광기 패턴 없는 적 11종에 대한 정신공격 가치 보장책. 구현 시 `StatusDamageCalculator` 래핑 영역(상시 배율 전례) + 수치 = Balance 외부화. 채택 여부 = 프로토타입 검증 후 확정 원칙.
2. `HeraldEscort` 조우의 신도 등장 구간 상향 여부 (3-2절 ⚠).
