## 1. 작업 순서 (개정 1 — 검증 소화 순)

> **배열 원칙: 아트 순서 = 검증 소화 순서.** 실검증을 아트 시점으로 미룬 근거가 "아트 적용 상태가 직관적"(개정 25)이므로, 검증 이월분이 가장 밀집된 화면부터 아트를 입혀 단계마다 이월 검증을 한 묶음씩 소화한다 — 플레이어가 가장 오래 보는 화면 순 = 검증이 가장 많이 쌓인 화면 순.

**Step 1. 한글 폰트 + 공통 UI 킷** (S1 픽셀 기준 + S5 폰트 확정 → S3 공통 9-slice 프레임·버튼 1세트) — **최소 비용 즉효:** 폰트 하나로 전 화면 텍스트 가독성이 올라 이후 모든 검증의 직관성이 개선. 공통 킷은 뒤의 팝업 5종이 전부 재사용

**Step 2. 전투 화면** (S4 카드 규격 확정 → CardView 프레임 + 5-1 잔여(AP·타입 텍스트·반응형 마커) → 게이지(GaugeView/UIGaugeView) → IntentView 아이콘 → MadnessOverlayView·PartyStatusView·BattleHUDView) — **검증 밀집도 최대:** 씬 검증 최대 덩어리(5-1·5-3~5-6) + M3 취약·M5 어그로/도발/Self 드래그 전부 이 화면에서 소화. **게이지·의도가 명확해야 이후 적/보스 검증(배율·페이즈 전환·의도 갱신)을 눈으로 판정 가능 — 전투 아트가 곧 검증 도구.** 카드 규격은 콜라이더·호버 판정 파급이 최대라 조기 고정 = 재작업 리스크 최소

**Step 3. 적 스프라이트 + 에셋 제작** (3장 체크리스트 — 상태이상 5종·적 13종·조우 15종·챕터 SO 풀 등록·보스) — 전투 화면 완비 상태에서 투입 → **데이터 문서 실검증 시나리오(층 필터 → 골렘 페이즈 → 전령 광기 → 보스) 즉시 가동.** 순서 역전 시 목업 화면 검증 = 직관성 상실

**Step 4. 맵 화면** (노드 타입 아이콘·방/복도·침식/광기 간선 표시 — MapView) — 노드 타입이 아이콘으로 구분돼야 런 루프 검증(M2 저장/복원·침식·광기 통행)이 직관적. **이 시점부터 P2-M8 실플레이 완주 검증 가능**

**Step 5. 마을 + 팝업** (건물 스프라이트 → V1 마을 팝업 → V2 서고 — 2장 명세) — M6 마을 시나리오 소화 + 테스트 버튼 2종·클릭 로그 제거

**Step 6. 신규 뷰 잔여** (V3 보상 → V4 상점 → V5 보관 선택 → V6 결과 — 2장 명세) — 런 루프 밖이라 후순위. **V3 보상 화면이 최고 가치** (테스트 버튼 5종 제거 + 카드/유물 획득 실경로) — M7 시나리오(유물·해금·보상·상점) 소화

**Step 7. 실검증 잔여 마감** (5장 목록 대조 — 각 Step에서 소화된 항목 확인 + 잔여 일괄: P2-M8 실플레이 완주·보관 이중 지급 수정 검증·미결정 8건 확정 상태 점검)

## 5. 실검증 일괄 목록 (Step 5 — 출처별 인덱스)

1. **Phase 1 씬 검증 이월** — 5-1 잔여 반영 확인 + 5-3~5-6 (게이지·의도·툴팁·HUD·광기 오버레이) → **Step 2**
2. **M2 저장/복원** — 이어하기·미해결 노드 재진입·버전 불일치 폐기 → **Step 4**
3. **M3 취약** — 부여 → 배율 → 감소 → 만료 (개정 13 시나리오) → **Step 2**
4. **M4 파티** — 편성 선택/토글 → 3인 전투 → 아군 드롭 → 적 표적 표시 → v2 저장 복원 (개정 17 시나리오) → **Step 2·4**
5. **M5 타겟팅** — 어그로·도발·Self 드래그 조준 (개정 18 시나리오) → **Step 2~3**
6. **M6 마을·드랍·회수** — 개정 20 시나리오 전체 + 팝업 도입 후 항목 → **Step 5**
7. **M7 유물·해금·보상·상점** — 개정 22·24·25 시나리오 (설계도 해금·발견형·드랍형·구매/제거) → **Step 5~6**
8. **데이터 문서 시나리오** — 층 필터·대상 규칙·골렘 페이즈·전령 광기·보스 (페이즈 2단 최저 임계값·광기의 페이즈 우선·처치 = 던전 승리) → **Step 3**
9. **P2-M8 실플레이 완주** — DoD 전 구간: 거점 → 편성 → 런 완주 → 회수 → 복귀 → 해금 + **보관 이중 지급 수정 검증** (보관 노드에서 화면 완료 전 종료 → 재로드 → 재전송 없음 확인) → **Step 4 이후 가능·Step 7 마감**
10. **침식·광기 통행·휴식 회복·결의 판정** (개정 9·21 이월) → **Step 4**

## 6. 아트 단계 중 확정할 미결정 (누적 정리)

1. 보스 광기 방향 — 탈진 락 vs 강화 통일 (데이터 문서 미결정 3)
2. 보스 유물 지급 시점·방식 (V3와 함께)
3. 골드 런 종료 처리 — 소멸 vs 일부 회수 (V6과 함께)
4. 던전 종료 자동 복귀 흐름 (V6과 함께)
5. 보관 전송 개수 제한·보관고 연동 (V5와 함께)
6. 상점 A안 재검토·재고 등급 분포 (V4와 함께)
7. HeraldEscort 신도 구간 상향 (에셋 제작 시)
8. 광기 보상 공통 이득 — 프로토타입 검증 후 (실검증 시)
